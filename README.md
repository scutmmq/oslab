# 操作系统课程设计 3.1 基础必做

本项目根据 `doc/操作系统课程设计内容与要求1.pdf` 的 3.1 基础必做要求实现，采用 C 语言完成一个控制台式操作系统实验集合。

## 已实现模块

1. 处理机调度
   - FCFS 先来先服务
   - SJF 非抢占式短作业优先
   - RR 时间片轮转
   - 非抢占式优先级调度，优先级数值越小越高
   - 输出运行顺序、完成时间、周转时间、等待时间、响应时间和平均值

2. 内存管理
   - FIFO 页面置换
   - LRU 页面置换
   - 首次适应动态分区分配
   - 最佳适应动态分区分配
   - 展示分配、回收、合并空闲分区和缺页统计

3. 进程同步与并发控制
   - 生产者-消费者问题
   - 读者-写者问题
   - 哲学家进餐问题
   - 使用 `pthread`、互斥锁和信号量实现并发模拟

4. 文件系统
   - 简易块式文件系统模拟
   - 支持创建、写入、读取、删除、列目录和格式化
   - 使用空闲块位图管理空间

## 构建与运行

推荐使用 CMake：

```bash
cmake -S . -B build
cmake --build build
./build/oslab_app
```

在 Windows/MinGW 环境下可运行：

```powershell
cmake -S . -B build
cmake --build build
.\build\oslab_app.exe
```

也可以直接使用 GCC：

```bash
gcc -std=c11 -Wall -Wextra -Iinclude src/main.c src/scheduler.c src/memory.c src/filesystem.c src/sync_demo.c -o oslab_app -lpthread
./oslab_app
```

## 使用说明

程序为控制台菜单式交互，启动后输入对应数字选择功能，进入各模块后按屏幕提示输入参数。

- **处理机调度**：先输入进程数量，再依次输入每个进程的 `pid 到达时间 服务时间 优先级`（四个数字空格分隔，优先级数值越小越高）。
  随后选择算法 `1.FCFS 2.SJF 3.RR 4.优先级 5.四种算法对比`，RR 与对比功能会再询问时间片大小。
  例如：数量输入 `3`，第一个进程输入 `1 0 4 2`。结果给出运行顺序与完成/周转/等待/响应时间（周转=完成-到达，等待=周转-服务，响应=首次运行-到达）。
- **内存管理**：
  - 页面置换：输入页框数量、访问序列长度，再输入页号序列（如 `1 2 3 2 4 1 2`），选择 FIFO 或 LRU，输出每步内存块状态与缺页率。
  - 动态分区：先输入内存总大小，再循环进行首次/最佳适应分配、回收、显示；相邻空闲分区自动合并。
- **进程同步**：选择生产者-消费者 / 读者-写者 / 哲学家进餐，程序创建多线程运行演示，输出为各线程交替打印（顺序每次可能不同属正常现象）。
- **文件系统**：先创建文件再写入/读取，再次写入会覆盖原内容；支持删除、列目录、格式化。文件系统仅存于内存，退出即清空。

各模块菜单中选 `0` 返回上级或退出。

## 测试

项目包含核心算法测试：

```bash
cmake --build build
ctest --test-dir build --output-on-failure
```

当前测试覆盖：

- FCFS、SJF、RR 的运行顺序和时间统计
- FIFO、LRU 的缺页次数和命中次数
- 首次适应、最佳适应的分配与回收合并
- 简易文件系统的创建、写入、读取、删除和空闲块回收
